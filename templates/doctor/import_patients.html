Column Instructions

Headers are case-insensitive and can be in any order:

  • name * Required
    Full name of the patient (split into first & last name).
  • phone Optional
    10-digit mobile number (leading +91, 0, spaces, and dashes are stripped).
  • email Optional
    Valid email address. Used as login username if provided.
  • gender Optional
    Male, Female, or Other.
  • dob Optional
    Accepted formats: dd/mm/yyyy, dd-mm-yyyy, yyyy-mm-dd.
  • blood_group Optional
    One of: A+, A-, B+, B-, O+, O-, AB+, AB-.
  • address Optional
    Full residential address.
